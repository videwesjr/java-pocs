## gof-design-patterns
GOF Explain: https://refactoring.guru/design-patterns/catalog

Java POC implementing the 23 Gang of Four design patterns, one small self-contained example per pattern.

### Roadmap

#### Creational
- [x] Singleton
- [x] Factory Method
- [x] Abstract Factory
- [x] Builder
- [x] Prototype

#### Structural
- [x] Adapter
- [x] Bridge
- [x] Composite
- [x] Decorator
- [x] Facade
- [x] Flyweight
- [x] Proxy

#### Behavioral
- [x] Chain of Responsibility
- [x] Command
- [x] Interpreter
- [x] Iterator
- [x] Mediator
- [x] Memento
- [x] Observer
- [x] State
- [x] Strategy
- [ ] Template Method
- [ ] Visitor
