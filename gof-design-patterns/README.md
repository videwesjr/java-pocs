## gof-design-patterns

Java POC implementing the 23 Gang of Four design patterns, one small self-contained example per pattern.

### Roadmap

#### Creational
- [x] Singleton
- [x] Factory Method
- [x] Abstract Factory
- [ ] Builder
- [ ] Prototype

#### Structural
- [ ] Adapter
- [ ] Bridge
- [ ] Composite
- [ ] Decorator
- [ ] Facade
- [ ] Flyweight
- [ ] Proxy

#### Behavioral
- [ ] Chain of Responsibility
- [ ] Command
- [ ] Interpreter
- [ ] Iterator
- [ ] Mediator
- [ ] Memento
- [ ] Observer
- [ ] State
- [ ] Strategy
- [ ] Template Method
- [ ] Visitor
